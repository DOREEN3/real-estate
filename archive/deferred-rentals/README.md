# Deferred rental workflows

This archive preserves rental workflow sources and snapshots of shared files
as they existed before rental functionality was removed from the active API.
It is a source backup, not an active route or deployment target.

- `app/` contains the rental model/controller and original mixed payment and
  notification model/controller snapshots.
- `routes/` contains the original rental routes and mixed payment routes.
- `tests/` contains the original rental tests and tests covering rental paths.
- `docs/` contains the original rental, payment, and notification API docs.

No database tables, records, schema dumps, or SQL scripts were changed or
removed. Rental data remains in the database untouched.
